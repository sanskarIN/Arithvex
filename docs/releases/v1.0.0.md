# Arithvex v1.0.0

The first stable source and binary distribution of **Arithvex**, an open-source C++20 mathematical computing engine.

## Features

- Algebra: quadratic and cubic roots, factorization, combinatorics
- Statistics and probability: mean, median, mode, conditional probability and Bayes' theorem
- Numerical calculus: limits, derivatives, partial derivatives and definite integration
- Advanced numerical computation: matrices, Jacobi/power eigenvalue methods, FFT/IFFT, numerical ODE solvers, Taylor/Maclaurin series and constants
- Coordinate geometry: conics, planes, spheres, ellipsoids, paraboloids and hyperboloids
- Interactive `ArithvexCLI` command-line application
- Reusable native `Arithvex` shared library and installable CMake SDK

## Downloads

Release artifacts are built from the release commit, not from an older prerelease. Choose the file for your operating system:

- `Arithvex-1.0.0-Windows-AMD64.zip` — Windows x64 native CLI, library, headers and SDK
- `Arithvex-1.0.0-Linux-x86_64.zip` — Linux x86_64 native CLI, library, headers and SDK
- `SHA256SUMS.txt` — integrity hashes for both ZIP files

The automated publication process compiles Release builds on Windows and Linux, executes CTest, launches the installed CLI, builds **and runs** an external SDK consumer, audits archive contents, verifies checksums, and runs Linux AddressSanitizer and UndefinedBehaviorSanitizer checks before uploading the files.

## Getting started

See the [README](https://github.com/sanskarIN/Arithvex/blob/main/README.md) and [build guide](https://github.com/sanskarIN/Arithvex/blob/main/docs/BUILDING.md).

For SDK integrations, a CMake project can use:

```cmake
find_package(Arithvex 1.0 CONFIG REQUIRED)
target_link_libraries(your_app PRIVATE Arithvex::Arithvex)
```

## Numerical correctness improvements

The release includes guards for matrix and ODE size overflow, large 64-bit combinatorics, non-finite geometry parameters, and invalid prior-weight partitions in the law of total probability. Regression tests cover calculus, FFT, eigenvalues, constants, geometry and probability boundaries.

## Compatibility and limitations

- Only the named **Windows x64/MSVC** and **Linux x86_64/GCC** binary distributions are validated. macOS, ARM, 32-bit targets and cross-compiler ABI compatibility are not promised.
- `MathEngine*` exported symbol names are retained, but the DLL/so binary filename is now `Arithvex`. Rebuild/relink older clients or update explicit library loading paths.
- The export header has C linkage but uses C++ declarations (`std::size_t` etc.); it is intended for C++ consumers, not a portable plain C header.
- The `SymbolicCalculus` module currently evaluates numerical derivatives and integrals, not general-purpose symbolic algebra.
- Numerical precision depends on the algorithm and target platform. Review error sentinel values for invalid input.

See the [ABI and platform contract](https://github.com/sanskarIN/Arithvex/blob/main/docs/releases/v1.0.0-abi.md) for details.
