# Arithvex v1.0.0 — release readiness

**Status:** First stable release in preparation. **Do not create the `v1.0.0` tag or publish a stable release yet.** Build archives are explicitly labeled `1.0.0-rc.1` and are candidates for validation, not stable downloads.

## Proposed v1.0.0 scope

- C++20 numerical engine (algebra, statistics, probability, matrix tools, FFT, geometry and numerical calculus)
- Interactive `ArithvexCLI` executable
- `Arithvex` shared C ABI, with original `MathEngine*` types and function names retained
- `ArithvexCore` reusable static C++ core
- CMake installable SDK and `find_package(Arithvex CONFIG)` support
- Windows and Linux native archive distributions

## Breaking changes and migration notes

Relative to the legacy project, built binary names are now `Arithvex` and `ArithvexCLI` rather than `MathEngine`/`MathEngineRunner`. Clients that load the old DLL filename or executable path need to update packaging or loading logic. Original exported C ABI **function names remain unchanged**; existing binaries may require rebuild/relink for the new library filename and platform.

The public `MathEngineExports.h` declarations contain C++ types (including `std::size_t`), so they are a C-linkage ABI for **C++ consumers**, not a guaranteed plain-C-compatible header. Do not promise cross-compiler binary compatibility without explicit testing.

The C++ namespace alias `Arithvex = MathEngine` is available via `Arithvex.h`. CMake aliases for the historical target names exist only for consumers using the same build tree; the installed CMake package provides `Arithvex::Arithvex` and `Arithvex::ArithvexCore`.

## Release candidate procedure

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
cmake --install build --config Release --prefix install
cpack --config build/CPackConfig.cmake -C Release -G ZIP --package-directory dist
```

Build Windows artifacts on Windows and Linux artifacts on Linux; do not assume the archives are interchangeable.

## Before updating the package version to stable

In `CMakeLists.txt`, change `ARITHVEX_PRERELEASE` from `rc.1` to a stable value, revise the CPack package filename logic so it no longer includes a prerelease suffix, and update this document and release notes. The CMake project numeric version is `1.0.0` during release-candidate development; **this alone is not a stable release**.
